型通り他人【遊べるMV】 v7（PC・スマホ両対応）

■ ファイル（全部同じフォルダに置く）
index.html   PC版（横画面）
mobile.html  スマホ版（縦画面）
song.mp3     楽曲
title.jpg    タイトル画面
A-0〜A-7.png キャラ差分
B-1〜B-3.png 背景

■ GitHub Pages への置き方
リポジトリ music-video-mon-games.github.io の中に
  katadoori/  というフォルダを作り、このフォルダの中身を全部入れる
→ PC版   https://music-video-mon-games.github.io/katadoori/
→ スマホ版 https://music-video-mon-games.github.io/katadoori/mobile.html
（フォルダ名は英数字なら何でも可。index.html の名前は変えない）

■ 操作
PC     ：F＝左（戻ってくる） J＝右（送信）
スマホ ：画面の左半分タップ＝左、右半分タップ＝右

■ 録画（YouTube用）
PCで「オート再生」→ 3カウント → 自動でパーフェクト進行。
80コンボ目「ノー返信」だけ未配信になる。

■ URLパラメータ（確認用）
index.html?t=118        118秒から開始
index.html?offset=0.05  ノーツ全体の補正（秒。＋で遅く）

■ mp3 が自動で読めない環境
スタート画面の「mp3を選ぶ」で song.mp3 を指定
